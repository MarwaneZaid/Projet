## Comment prendre (Mac)

| Action | Touche |
|--------|--------|
| Écran entier | `Cmd + Shift + 3` |
| Zone précise | `Cmd + Shift + 4` puis sélectionner |
| Une fenêtre | `Cmd + Shift + 4` puis `Espace` puis clic sur la fenêtre |

Les fichiers arrivent sur le **Bureau** → renommer → glisser ici.

## Nom du fichier

Utiliser **exactement** le nom indiqué dans :

**[docs/wiki/screenshots-par-etape.md](../../wiki/screenshots-par-etape.md)**

Exemple : `01-proxmox_toutes-vms.png`

## Liste « où + comment + quoi »

Chaque capture y est détaillée avec :

- **Où chercher** (menu, URL, commande)
- **Comment** (raccourci Mac, quel écran)
- **Quoi montrer** (texte obligatoire sur l'image)
- **Fichier** + **dossier**

## Interdit sur les captures

- Mots de passe (champs ou terminal)
- Clés SSH **privées**
- Fichiers `.env`, tokens API, clés OVH
